मेरा AI सहायक — वेबसाइट फ़ाइलें

इस ZIP में वेबसाइट का तैयार कोड है। यह अपने-आप इंटरनेट पर प्रकाशित नहीं होती; इसे Node.js सपोर्ट वाले होस्ट पर चलाना होगा।

चलाने के लिए:
1. ZIP को कंप्यूटर पर खोलें।
2. Node.js इंस्टॉल करें।
3. इस फ़ोल्डर में टर्मिनल खोलकर चलाएँ: npm install
4. GEMINI_API_KEY को अपने होस्ट की Environment Variables / Secrets सेटिंग में डालें।
   API key को public HTML, स्क्रीनशॉट या किसी चैट में न डालें।
5. चलाएँ: npm start
6. ब्राउज़र में http://localhost:3000 खोलें।

ध्यान दें:
- मोबाइल पर सिर्फ ZIP डाउनलोड करने से वेबसाइट सार्वजनिक नहीं होगी।
- इंटरनेट पर प्रकाशित करने के लिए Node.js होस्टिंग चाहिए।
- अगर API key लीक हो गई हो, तो Google AI Studio में उसे revoke करके नई key बनाएँ।
